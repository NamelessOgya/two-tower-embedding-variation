# Insight: 端対端学習型マルチヘッド層化分割モデルの検証と考察 (Plan 015)

**実験**: Plan 015  
**データ**: MovieLens 1M | multilingual-e5-base (ZCA whitened) | K=10 | N_trials=10 | Seeds=5  
**目的**: Plan 014 の「無学習直交マルチヘッドのアライメント崩壊（`rc = 0.0196`）」を解決するため、10 個のマルチヘッド $W_1, \dots, W_{10}$ が各担当バケット $I_1, \dots, I_{10}$ 内の正解アイテムにアラインするように端対端（End-to-End）ファインチューニングを行ったモデルの性能を定量評価する。

## 2. Key Insights & 詳細分析

### Insight 1: 無学習マルチヘッドからの V字回復 (5.1 倍)
- **結果**: Plan 014 の無学習直交回転（`rc = 0.0196`, `Slate Precision = 0.20%`）に対し、バケット BPR 損失による端対端学習を行った Plan 015 では **`recall_cum = 0.0995`**（無学習比 **5.1 倍**）、**`Slate Precision = 0.89%`**（無学習比 **4.5 倍**）へと急回復した。
- **メカニズム**: 各ヘッド $W_t$ が担当バケット $I_t$ の潜在表現空間にアラインするように学習されたことで、クエリベクトルとアイテムベクトル間の内積適合度が正常化し、アライメント崩壊が完全に解決された。

### Insight 2: なぜ学習型マルチヘッドでも単一クエリ Item Partition (`0.1172`) を超えられないのか？
- **現象**: アライメントは回復したものの、`recall_cum = 0.0995` となり、単一クエリをそのまま使う `TT_semantic_stratified_partition_n10` (`0.1172`) の数値を下回った。
- **数理的・構造的要因**:
  1. **正例データのバケット別希薄化 (Sample Sparsity per Head)**:
     - 全訓練ペア $(u, i_{\text{pos}})$ が 10 個のバケットへ分割（各バケットあたり 1/10 のサンプル数）されたため、各ヘッド $W_t$ の最適化に使える正例数が 1/10 に激減し、各ヘッドの表現力（汎化性能）に過学習/データ不足による制約が生じた。
  2. **二タワー共通空間の表現力の完結性**:
     - Base のユーザーエンコーダー $\mathbf{q} = \text{user\_head}(u)$ は、ZCA 白色化も手伝って全アイテムとの広域アラインメント表現をすでに高精度に獲得している。そのため、追加のプロジェクション層 $W_t$ で局所変形を加えるよりも、ベースの高品質な $\mathbf{q}$ をそのまま使って各バケットから一貫した基準で上位を拾う方が、全体の Recall が最も高くなる。

---

## 3. 結論と統括

1. **マルチヘッド方式の教訓**:
   - マルチヘッドを導入する場合、無学習回転は厳禁であり、端対端（End-to-End）アラインメント学習が不可欠である（`0.0196` ➔ `0.0995`）。
2. **過去履歴非依存（ステートレス）条件での最終結論**:
   - 過去履歴を使わない完全ステートレス条件下において、精度・多様性・システム単純性のすべてで最も優れているのは **`TT_semantic_stratified_partition_n10` (意味論的層化アイテム分割)** である。
   - クエリ側に変形（マルチヘッド等）を加えず、基本クエリ $\mathbf{q}$ のまま層化分割されたアイテムバケットを順次引く構造が、数理的にも実用的にも最もロバストで最高性能を発揮する。
