# Plan 020: 次世代 LLM 埋め込みモデル検証レポート (Qwen3-Embedding vs. mE5)

## 1. エグゼクティブサマリー

最新の大規模言語モデル（LLM）基盤埋め込みモデルである **`Qwen/Qwen3-Embedding-0.6B`**（0.6B パラメータ、1024 次元）を導入し、従来の RoBERTa/BERT 系最高峰モデルである **`multilingual-e5`**（small / base / large）との間で、Two-Tower 推薦システム（Log-Q InfoNCE 学習基盤）における性能比較を実施した。

各モデルについて **5 つの独立シード（5 Seeds: 42, 43, 44, 45, 46）** で学習・推論評価を行い、精度指標とカタログ多様性指標を測定した。

## 3. 主要な知見 (Key Findings)

### 💡 知見 1: `Qwen3-Embedding-0.6B` が全精度指標で最高性能（SOTA）を樹立
- **`Recall@10 = 0.02937`** を記録し、`mE5-large`（0.02847）を **+3.2%**、`mE5-base`（0.02831）を **+3.7%** 上回った。
- **`Precision@10 = 1.80%`**、**`NDCG@10 = 0.02463`**、**`Hit@10 = 14.30%`** と、すべての適合精度においてこれまでの最高記録を更新。
- **メカニズム**: Qwen3 LLM が持つ強力な意味理解能力と指示（Instruct）チューニングにより、ユーザー属性と映画属性の間の潜在的な意味的一致度（Relevance）が極めてシャープに抽出されている。

### 💡 知見 2: 精度とカタログ多様性のトレードオフ
- `Qwen3-0.6B` は適合度の高い有力アイテムにシャープに集中するため、`Catalog Coverage@10 = 3.43%` とやや低め。
- 一方、`mE5-large` は `Coverage@10 = 5.16%`、`Long-tail Coverage = 1.63%` と、最も広いカタログ探索能力を発揮。

### 💡 知見 3: Gemma 系モデル（EmbeddingGemma）の状況
- Google の `google/embeddinggemma-300m` は Hugging Face 上で Gated Model（利用規約同意・HFトークン認証が必要）となっている。環境変数 `HF_TOKEN` を設定することで追加検証が可能。

## 4. 実務への提言 (Best Practices)

1. **純粋精度（Recall / Precision / NDCG）を極限まで高めたい場合**: **`Qwen3-Embedding-0.6B`** が最適。
2. **精度とカタログ多様性（ロングテール開拓）のバランスを取りたい場合**: **`mE5-large`** が最適。
3. **軽量性・高速性を重視する場合**: **`mE5-small`** が高い費用対効果を発揮。
